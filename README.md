# Hi, I'm Rafael 👋

I'm a software engineer building enterprise software for manufacturing and distribution: Acumatica ERP customizations, integrations, and the internal web apps (React, TypeScript, Node.js) that sit on top of them. I work at a jewelry manufacturer and distributor in New Jersey, where about 60 warehouse and office staff use what I build every day.

My work is private, so here is what it did:

- **Cut warehouse scan time 73%** (5.2 s to 1.4 s) and database calls about 90% by profiling the ERP and fixing queries that ran once per row.
- **Built a carton-packing web app** after packing in the ERP proved too slow: scans are checked in the browser, and each finished carton saves to the ERP in one API call.
- **Made a large order-processing run 62% faster.**
- **Replaced a $15.6K vendor estimate** by building shipping-label printing in-house.
- **Wrote a Python tool** that turns a 300-column order spreadsheet into barcoded packing-slip PDFs, about 340 orders in under a minute.
